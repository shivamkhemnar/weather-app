⚙️ Integrations & refresh

Add your free API keys (your manual step)

  1. Weather: openweathermap.org/api → sign up → copy key.
  2. Traffic: developer.tomtom.com → sign up → Traffic Flow API → copy key.
  3. In C:\weather, copy .env.example to .env, paste both keys, save.
  4. Restart the server. Status above flips to LIVE.
